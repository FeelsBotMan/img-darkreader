# 다크 리더(Dark Reader) 사용 설명서

데스크톱에서 이미지 폴더를 **책처럼** 열어 읽는 뷰어입니다. 다크 모드에서는 페이지를 **색상 반전**하여 눈의 부담을 줄이고, OpenCV **Lanczos** 기반 업스케일을 백그라운드에서 수행합니다.

## 1. 기능 요약

| 구분 | 설명 |
|------|------|
| **라이브러리** | 한 번 연 폴더는 책으로 등록되며, 썸네일·진행 페이지·별점이 유지됩니다. |
| **다크 모드** | RGB 전역 반전 후 밝기 보정으로 읽기 쉬운 톤을 만듭니다. |
| **라이트 모드** | 반전 없이 대비·선명도를 약하게 올립니다. |
| **페이지 이동** | ← → 로 이전·다음 이미지, 자연 정렬(파일명 숫자 순 등). |
| **업스케일** | 현재·다음 페이지를 2배 Lanczos로 처리해 캐시에 저장합니다(비동기). |
| **북마크** | 현재 페이지를「문제」「정답」위치로 저장하고 단축키로 점프합니다. |

## 2. 실행 환경 및 설치

- **Python**: 3.9 이상 (`pyproject.toml` 기준)
- **주요 의존성**: PyQt6, Pillow, PyYAML, NumPy, OpenCV(opencv-python)

저장소 루트에서 가상환경을 만든 뒤 패키지를 설치합니다.

```bash
python -m venv venv
# Windows (Git Bash 등)
source venv/Scripts/activate
# Linux / macOS
# source venv/bin/activate

pip install -e .
```

의존성 목록은 `pyproject.toml`의 `[project]`가 기준이며, `requirements.txt`는 참고용일 수 있습니다.

## 4. 화면 구성

### 4.1 라이브러리 화면

- 등록된 **책(폴더)**이 카드 그리드로 표시됩니다.
- 카드에는 **표지 썸네일**, **제목(폴더명)**, **읽은 위치 / 총 페이지**, **별점(0~5)**이 보입니다.
- 카드를 **더블클릭**하면 해당 폴더를 열고 **리더 화면**으로 전환됩니다.
- 창 너비에 맞춰 열 개수가 바뀝니다.

### 4.2 리더 화면

- 한 장의 이미지를 크게 표시합니다. 가로폭에 맞춰 비율을 유지하며 스케일합니다.
- **세로로 긴** 이미지는 스크롤로 위아래를 볼 수 있습니다.
- 하단 상태줄에 **업스케일 진행 여부** 등 메시지가 표시될 수 있습니다.
- **Esc** 로 라이브러리로 돌아갑니다.

---

## 5. 지원 형식 및 폴더 규칙

- **포함되는 파일**: 같은 폴더 안의 `.png`, `.jpg`, `.jpeg` (대소문자 무관)
- **정렬**: 자연 정렬(`natural_sort_key`) — `1.jpg`, `2.jpg`, `10.jpg` 순서가 기대에 맞게 정렬됩니다.
- 이미지가 **하나도 없으면** 경고 대화상자가 뜨고 해당 폴더는 읽기 시작하지 않습니다.

---

## 6. 단축키

포커스는 기본적으로 메인 창(리더에서는 리더 위젯)에 있습니다. **리더 화면**과 **전역**으로 나눕니다.

### 6.1 전역(라이브러리·리더 공통)

| 키 | 동작 |
|----|------|
| **O** | 폴더 선택 대화상자를 열고, 선택한 폴더를 책으로 추가한 뒤 리더로 진입합니다. |
| **T** | **다크 모드 ↔ 라이트 모드** 전환. 설정 파일에 `is_dark_mode`로 저장됩니다. |

### 6.2 리더 화면 전용

| 키 | 동작 |
|----|------|
| **←** | 이전 이미지 |
| **→** | 다음 이미지 |
| **Esc** | 라이브러리 화면으로 이동 |
| **[** | 대비(contrast) 테마 값 감소(0.1), 이미지 다시 표시 |
| **]** | 대비 증가 |
| **-** | 밝기(brightness) 감소 |
| **=** | 밝기 증가 |
| **,** | 선명도(sharpness) 감소 |
| **.** | 선명도 증가 |
| **X** | 현재 페이지를 **문제 위치**로 저장하거나, 이미 저장돼 있으면 **해제** |
| **S** | 현재 페이지를 **정답 위치**로 저장하거나 **해제** |
| **Z** | 저장된 **문제** 페이지로 이동 |
| **A** | 저장된 **정답** 페이지로 이동 |
| **H** | 단축키 설명 오버레이 |

> **참고**: `[` `]` `-` `=` `,` `.` 는 `Theme` 객체의 수치를 바꾼 뒤 화면을 갱신합니다. **다크 모드**의 메인 파이프라인은 코드상 고정 밝기 보정을 사용하므로, 이 단축키로 **체감 변화가 거의 없을 수 있습니다**. 라이트 모드 쪽 처리와의 정합은 버전에 따라 다를 수 있습니다.

## 7. 라이브러리와 진행도

- **O**로 연 폴더나 카드로 연 폴더는 `library.json`에 **책**으로 기록됩니다.
- 이미 등록된 경로를 다시 열면 **이전에 읽던 페이지**부터 이어집니다.
- 페이지를 넘길 때마다 **현재 페이지 인덱스**가 저장됩니다.
- **마지막 페이지**에 도달하면 **완독**으로 표시될 수 있습니다.
- 카드에서 **별**을 클릭해 **1~5점** 평점을 주거나, 같은 점수를 다시 눌러 **0으로 취소**할 수 있습니다.

---

## 8. 문제·정답 북마크

학습·문제집처럼 **한 책(폴더)당** 하나씩, 대표 **문제 페이지**와 **정답 페이지** 위치를 기억할 수 있습니다.

- **X** / **S** 로 토글 저장합니다.
- **Z** / **A** 로 저장된 인덱스로 점프합니다.
- 저장 정보는 `library.json`의 해당 책 항목에 포함됩니다.

---

## 9. 이미지 처리 동작

### 9.1 다크 모드

1. RGB로 통일한 뒤 픽셀 값을 `255 - 값` 으로 **반전**합니다.
2. 그 결과에 고정 비율(**약 1.3배**) 밝기 스케일을 적용하고 0~255로 클립합니다.

### 9.2 라이트 모드

- PIL `ImageEnhance`로 대비·선명도를 약하게 올린 이미지를 보여 줍니다.

### 9.3 업스케일(백그라운드)

- OpenCV `INTER_LANCZOS4`로 가로·세로 **2배** 리사이즈합니다.
- **메모리 캐시**와 **디스크 캐시**를 사용합니다.
- 현재 페이지 표시 후 **다음 2장**은 `prefetch`로 미리 큐에 넣습니다.
- 상태줄에 **「업스케일링 처리 중…」** / **「업스케일링 완료」** 형태로 표시됩니다.

> 표시 파이프라인은 우선 **반전·보정된 원본 해상도**를 쓰고, 업스케일은 캐시·비동기 처리와 연동됩니다. 동작 세부는 버전별로 조정될 수 있습니다.

## 10. 설정 파일

경로: **사용자 홈 디렉터리** 아래

`%USERPROFILE%\.dark_reader\config.yaml` (Windows)  
`~/.dark_reader/config.yaml` (Linux / macOS)

프로그램이 읽고 쓰는 항목은 다음과 같습니다.

| 키 | 설명 | 기본값 예 |
|----|------|-----------|
| `is_dark_mode` | 다크 모드 여부 (`T`로 전환 시 저장) | `true` |
| `threshold` | 설정 파일에 **저장·로드**됩니다. | `240` |

`threshold`는 현재 이미지 처리 코드에서 **읽어 쓰기만 하고**, 흰색 마스킹 등에 **연결되어 있지 않을 수 있습니다**. 향후 확장을 위한 필드로 이해하면 됩니다.

`Theme`에 정의된 **배경색·글자색** 등은 UI 테마·스타일시트에 쓰이며, **이 YAML 키로 자동 덮어쓰기되지는 않습니다**. 색을 바꾸려면 코드의 기본 테마나 스타일을 수정하는 방식이 해당 버전에서는 맞습니다.

## 11. 데이터가 저장되는 위치

| 용도 | 경로 |
|------|------|
| 설정 | `~/.dark_reader/config.yaml` |
| 라이브러리·책·진행도·북마크 | `~/.dark_reader/library.json` |
| 라이브러리 썸네일 캐시 | `~/.dark_reader/thumbnails/` |
| 업스케일 결과 캐시 | `~/.img-darkreader/cache/` (파일명: `{원본스템}_upscaled{확장자}`) |

백업이나 초기화 시 위 폴더·파일을 대상으로 하면 됩니다.

## 12. 문제 해결

| 증상 | 확인할 것 |
|------|-----------|
| 프로그램이 안 뜸 | 가상환경 활성화 여부, `pip install -e .`, Python 버전 ≥ 3.9 |
| 폴더를 열어도 이미지 없음 | 확장자가 `.png` / `.jpg` / `.jpeg` 인지, 하위 폴더는 스캔하지 않음 |
| OpenCV 관련 오류 | `opencv-python` 설치 여부 |
| 한글 경로 이미지 | 업스케일러는 `cv2.imdecode` 경로로 한글 경로를 고려함 |
| 캐시 용량 | `~/.img-darkreader/cache` 및 `~/.dark_reader/thumbnails` 정리 |
